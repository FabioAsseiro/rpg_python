# ⚔️ RPG em Python

Um RPG de aventura desenvolvido em **Python**, criado como um projeto pessoal para praticar programação, lógica e conceitos de orientação a objetos.

O projeto começou inspirado em um RPG apresentado no canal [Olá, Python!](https://www.youtube.com/@Ol%C3%A1Python), mas está sendo desenvolvido com **minhas próprias ideias, mecânicas e propostas para o jogo**.

> 🚧 **Projeto em desenvolvimento:** novas mecânicas, sistemas e funcionalidades serão adicionados conforme o projeto evolui.

---

## 🎮 Sobre o projeto

A ideia é criar um RPG baseado em texto, executado diretamente pelo terminal, onde os jogadores poderão criar seus personagens, evoluir durante uma aventura e enfrentar diferentes desafios.

O projeto também tem como objetivo servir como uma forma prática de estudar e aplicar conceitos de Python enquanto o jogo é desenvolvido.

Entre os conceitos que pretendo trabalhar estão:

* 🧙 Criação e gerenciamento de personagens
* ⚔️ Sistema de combate
* 🗺️ Exploração e aventura
* 📈 Sistema de experiência e níveis
* 💰 Sistema de ouro
* 🛡️ Armas e armaduras
* 👾 Inimigos
* 🎒 Inventário
* 🎲 Eventos e aleatoriedade
* 👥 Possibilidade de jogar com vários jogadores localmente
* 📖 Progressão baseada em aventura

---

## 🧠 Objetivo

Mais do que criar um jogo, este projeto está sendo desenvolvido como uma forma de **aprender Python na prática**.

Durante o desenvolvimento, estou utilizando o projeto para praticar conceitos como:

* Classes e objetos
* Programação Orientada a Objetos (POO)
* Listas e estruturas de dados
* Funções
* Condicionais
* Loops
* Entrada e validação de dados
* Manipulação de estados
* Geração de valores aleatórios
* Organização e estruturação de código

A ideia é evoluir o projeto gradualmente, tornando o código cada vez mais organizado enquanto novas mecânicas são adicionadas.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/FabioAsseiro/rpg_python.git
```

Entre na pasta:

```bash
cd rpg_python
```

Execute o projeto:

```bash
python main.py
```

Caso esteja utilizando o **UV**:

```bash
uv run main.py
```
